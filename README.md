# 📚 Library Management System

A web-based Library Management System developed as a practical project using PHP and MySQL.

This project allows users to register, log in, and manage different parts of a library through a simple web interface.

## ✨ Features

- User Registration and Login
- User Dashboard
- Book Management
- Member Management
- Librarian Management
- Sales Management
- Logout System

## 💻 Technologies Used

- HTML
- CSS
- Bootstrap
- PHP
- MySQL
- XAMPP

## 🚀 How to Run the Project

1. Install XAMPP.
2. Copy the project folder into the `htdocs` folder.
3. Start Apache and MySQL in XAMPP.
4. Open phpMyAdmin.
5. Create a database named `librarydb`.
6. Import the `librarydb.sql` file.
7. Open the project in your browser using:
   `http://localhost/library/login.php`
